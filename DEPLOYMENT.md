# Vercel deployment checklist

- [ ] Push website source to GitHub.
- [ ] Import repository into Vercel using the Next.js preset.
- [ ] Confirm Node.js 20.9+ is selected.
- [ ] Configure only real public release/source/contact links.
- [ ] Keep the release URL blank until a signed-off installer is published.
- [ ] Replace illustrative screenshot placeholders with real app screenshots.
- [ ] Review privacy and password-storage claims against the application source.
- [ ] Run a production build and check mobile navigation, FAQ, anchor links, and 404.
- [ ] Verify the download target, release notes, and SHA-256 checksum independently.
- [ ] Attach the production domain and confirm HTTPS.
